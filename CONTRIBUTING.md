# Werken met branches

- **`main`** — live GitHub Pages: https://dburgers84.github.io/vve-van-speijk-kaart/
- **`dev`** — doorontwikkeling; wijzigingen via pull request naar `main`

## Flow
1. Werk op `dev` (of een feature-branch vanaf `dev`).
2. Open een PR `dev` → `main` (of feature → `dev` eerst).
3. Na merge op `main` is Pages binnen een paar minuten bijgewerkt.
